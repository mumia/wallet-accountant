**For the user (nothing below has been done):**

1. **1Password items** (vault `homelab-infra`), with the commands in env `clusters/prod/secrets/README.md`, step 1: `zitadel-masterkey` (exactly 32 characters, never regenerated), `zitadel-admin`, `grafana-admin`, `apps-db-wa-owner`, `apps-db-wa-app`, `apps-db-wa-event-store-reader`, `ntfy-topic`, and `ovh-cert-manager`. `ovh-cert-manager` is a second OVHcloud API key for cert-manager only: create it at https://eu.api.ovh.com/createToken/ with the rights listed there. `sops-age-key` comes from ticket 10's runbook (`infra/README.md`, step 2), with a printed copy.
2. **Age recipient:** put `op read "op://homelab-infra/sops-age-key/public key"` in both rules of `.sops.yaml`.
3. **Seal:** install `sops`, run `clusters/prod/secrets/seal.sh`, then `REQUIRE_ENCRYPTED=1 clusters/prod/check.sh`, then commit (ciphertext only). Do this **before** `main` carries `clusters/prod/kustomization.yaml` to a running cluster: Flux would otherwise apply the template text. Check once that `op inject` leaves ntfy's `{{.message}}` templates alone; `seal.sh` refuses to write if anything other than the references changed.

5. **GHCR:** make the two packages public after the first release (conventions, "Releases"), so the ImageRepositories and the OCIRepository pull without credentials.
6. **First run,** after `tofu apply` (`infra/README.md`, step 5) and the steps above: follow env `clusters/prod/README.md`, "First run". Watch `kubectl -n gateway get certificate wildcard` reach Ready on staging. Then set `CLUSTER_ISSUER: letsencrypt-prod` in `platform.yaml`, push, and `kubectl -n gateway delete secret wildcard-tls`.
